2. 澄清：多主题上文下的模糊追问返回可访问主题选择；不把选项中的资料名当成授权。
3. 章节：Markdown 标题与 Word Heading 样式分块，保留章节与行号；检索后只增加同文档、同版本、同章节的授权相邻片段。
4. 门禁：固定 dev 集阈值、相对 v4.1 基线比较、题数和数据集校验、缺失/NaN 指标拒绝、权限泄漏非零失败；默认离线 CI，PostgreSQL 作为手动选跑项。
5. 清理：用户记录导出、默认预览、显式执行、按会话活动时间保留、用户/租户隔离、保留活跃任务与租约；可选修剪拥有的非活跃资料旧版本。
6. 展示：重写 README，加入六分钟讲解路线、无需模型 Key 的演示脚本与可上传章节样例。

没有新增 Python 依赖或必需的外部服务。
